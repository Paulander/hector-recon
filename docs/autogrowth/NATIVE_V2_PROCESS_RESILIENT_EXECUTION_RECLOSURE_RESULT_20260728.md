## Implementation result

1. A/seed-00 through A/seed-31;
2. B/seed-00 through B/seed-31;
3. C/seed-00 through C/seed-31.

Each unit has a chained atomic PREPARED record and a chained atomic COMMITTED
record. Only a complete COMMITTED record can enter aggregation. Restarts
revalidate every committed unit; an unfinished outcome-blind unit is
recomputed with an explicit additional preparation record. Changed, missing,
duplicated, reordered, or foreign records stop.

The completed unit set deterministically rebuilds the three registry
adjudications, row parity, target opportunities, admission decision, exposure
file, execution manifest, and a marker binding both final files. Existing
partial finalization files are accepted only when byte-exact.

will mark the complete suffix consumed. Outcome counts and event identities
come from the validated durable journal. Invalid journal reconstruction yields
`unknown`, never a fabricated zero. A caught program failure, FAILED record,
or unfinished prepared outcome seed is terminal.
