# Native terminal-trace and learning-authority closure

Date: 2026-07-20
Scope: behavior-preserving engineering on the already-touched 64-event training tape and already-viewed 32-row development tape.

## Frozen hypothesis and null

Hypothesis: the frozen competence-envelope behavior can be reproduced when inference and learning consume only the selected option's formal graph trace and an environment-minted real-outcome receipt, while lifecycle wiring, specialization mode, and genome identity are persistent organism configuration.

Strongest null: removing laboratory reconstruction and injected eligibility changes actions, signals, correction/responsibility emissions, proposal/lifecycle behavior, final cells, or cohort metrics. Any such mismatch is an instrument abort and keeps regression sealed.

The changed engineering factor is authority ownership only. The learner, thresholds, capacities, three structural rounds, evidence order, outcomes, genome seeds, R0 policy, and all scientific data are unchanged.

## Learner/laboratory boundary

The graph emits one selected option and an immutable GraphSignalTrace. The trace contains its frame and source identities, complete GraphActuation, confirmed base terminals, confirmed mature StemCell identities, typed provenance, and exactly one POLICY_RESPONSE when an actuator exists. Captures occur before another candidate resets runtime. Only the graph-selected capture is returned.

The chess environment adapter executes the exact graph actuator and its completion terminal mints a signed immutable GroundedOutcomeReceipt. The receipt binds a unique event ID, a separate context fingerprint, the complete trace, predecessor/successor, completion-terminal identity/role/provenance, and observed terminal result. It independently re-executes R0 and verifies the exact transition. VIRTUAL traces cannot mint receipts.

The production organism accepts only receipts. It derives CompetenceEvidenceRecord internally. Its public learning calls expose no evidence record, signal tuple, completion Boolean, fabricated REAL frame, lifecycle flag, specialization mode, genome, parent identity, candidate identity, or eligible set.

This is a capability boundary, not a universal Python sandbox.

## Internal specialization contract

The candidate identity vocabulary comes only from typed graph-emitted terminal signals retained by the requested parent. SPECIALIZATION_ELIGIBILITY receives one frozen internal snapshot containing the evidence ledger, current grounded record, parent-local retained state, specialization mode, and frozen minimum support.

For each parent/member leg, the terminal itself calculates:

- supporting evidence count;
- absence from the current contradiction for local contrast;
- absence from the parent's recursively implied members;
- parent maturity/depth/request state;
- membership in the typed allowlist (BASE_TERMINAL, MATURE_COMPOSITE).

The former semantic string blacklist and eligible_specialization_pairs environment input are removed.

## Continuation manifest V3

V3 contains persistent configuration and wiring, genome identity/seed, feature-extractor identity, completion-terminal contract, accepted receipts/events, event counter, R0 canonical topology/weight/credit/lifecycle identities, source manifest, all envelope evidence/cells/lineage/polarity/lifecycle/counts/proposal ordinals, complete StemCell hashes, canonical graph snapshot, predicate-role registry, counters, and audits.
