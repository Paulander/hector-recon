# Native V2 portable admission bridge — preregistration

## Scope and stop boundary

This is one admission-only transport-identity closure. It preserves the frozen
V2 learner, cohort, exposure journal, exposure artifact, execution manifest,
completion marker, stop report, diagnostic, and all 96 organisms. It does not
run exposure, construct the outcome environment, run science, or access any
learning, R1, retired-65, regression, held-out, or fresh data.

## Hypothesis

A newly restored cohort can differ in raw pickle memo sharing while retaining
the complete existing `V2SnapshotCodec.semantic_identity`, exact outcome-blind
commitments, projections, scans, and all non-transport unit-result fields. If
that is true, the historical registry can be reconstructed from verified fresh
semantic fields plus the original journal-bound payload hashes, and the three
committed artifacts can be reproduced byte for byte.

## Frozen comparison law

Every leaf of each covered object is assigned exactly one of
`SEMANTIC_EXACT`, `HISTORICAL_TRANSPORT`,
`DERIVED_FROM_HISTORICAL_TRANSPORT`, or `STATIC_FROZEN`. The field
classification is frozen before a real restore. New or missing fields fail.
The unit-result portable comparison excludes only:

- `/unit_binding_digest`;
- `/scan_wrapper/registry_id`;
- `/scan_wrapper/payload_sha256`;
- `/unit_result_digest`.

Source snapshot raw/compressed hashes and manifest bindings remain static and
exact. The full existing semantic identity is compared canonically; no selected
summary replaces it.

## Verification order

The unchanged historical validator first verifies the original 96 PREPARED and
96 COMMITTED records and complete chain. A fresh runtime then restores all 96
organisms, proves explicit pre-outcome state, compares complete semantic
identities and portable bindings, performs only outcome-blind scans, and
compares complete portable unit results. Historical payload hashes are not
inserted into a registry until every fresh comparison passes. Each reconstructed
historical registry adjudicates only the stored wrappers; each fresh registry
scans only its own fresh payloads. Exposure, execution, and completion bytes
must then reproduce exactly.

## Processes and gates

Exactly three predeclared fresh module processes run independently. Each must
pass 96 complete semantic identities, 96 portable bindings, 96 portable unit
results, all three historical registry reconstructions, all three exact
artifacts, 195 protected files, zero mutation, and zero outcome access. A
read-only verifier follows each process and a read-only aggregate comparison
requires identical cohort, registry, and artifact results across all three.

After the package freeze, any discrepancy, mutation, new dependency,
unclassified field, or outcome access is terminal. No allowlist may be widened
and no failed attempt may be replaced or rerun in this package.

## Permitted conclusion

Success is reported only as: “Portable admission and exact historical
reconstruction passed.” It is not a learning, mechanism, or KRK result.
