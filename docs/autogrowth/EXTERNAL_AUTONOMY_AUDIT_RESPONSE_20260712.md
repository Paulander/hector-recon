# External Autonomy Audit Response

Date: 2026-07-12. Verdict: accepted as a falsification of the current
end-to-end autonomy interpretation.

## Blunt correction

The branch has improved the combined human/LLM/Python/ReCoN research system.
It has not yet shown that ReCoN owns its developmental loop. The current native
KRK runner is an honest empty-learned-state and outcome-grounded engineering
harness, but its laboratory still owns exploration, episode boundaries,
competence identities, maturity, freezing, availability, structural epochs,
curriculum order, and much of representation.

Therefore the current result may support claims about the formal graph substrate,
outcome-driven R0 learning, durable experiments, and oracle-assisted hierarchical
credit. It does not support "self-growing end-to-end ReCoN solves KRK."

## Evidence that triggered the correction

### Foundation-pool inversion

The first factorial attempt used all newly generated balanced R0 rows and ended
15/16 validation plus 15/16 regression after 48 epochs. Its stable misses were
positions already present in the retired-failure manifest. Restoring that
manifest regenerated the earlier easier pool and reproduced 16/16 plus 16/16 at
epoch 8.

Retiring exposed rows from confirmation was correct. Excluding them and their
symmetries from training as well meant the ecology did not learn the exception;
the laboratory changed the problem. The 16/16 rerun is a reproducible engineering
foundation on a named pool, not evidence of adaptation to the hard case.

### Learned availability has zero successor coverage

The corrected factorial cloned the reproduced R0 foundation. The no-bootstrap
arm completed 640 episodes at 0/16 validation, 0/16 regression, and 16/16 R0
retention. The learned-gate/learned-value arm reached immutable epoch 30 before
the audit-directed pause:

- 466 availability queries;
- 0 availability positives;
- 0 child handoffs;
- 0 delivered successor value;
- 0/16 validation in every R1 stratum;
- 16/16 R0 retention.

Thus the outcome-calibrated host gate does not recognize the actual R1 successor
distribution. Value content cannot be evaluated when availability never fires.

### Semantic and measurement defects

- `real_child_rollout` and `virtual_frame_verified` both selected the frozen
  child on a copied board and observed the same terminal helper. The "real"
  label and self-authored test did not create a distinct environment trajectory.
- Main routing-on evaluation was repeated in the routing ablation, adding large
  compute without information.
- Composition eligibility still used an `R1_` diagnostic-string filter despite
  the constitution banning laboratory stage metadata from structural causes.
- Training estimates sampled/expected Black reply return while the KRK gate is
  worst-reply conversion.
- Intrinsic TD predicts from an exact-triplet value while action choice scores a
  different terminal/composite-weight sum. The corrected prediction is not
  clearly the prediction that chose the action.

## Limited qualifications

Round-robin action exposure, authored sensors, host competence IDs, and hard
freeze are legitimate experimental controls. They become errors only when their
success is attributed to learner autonomy. Likewise an evolved relational genome
need not be prior-free. The scientific requirement is to freeze it across tasks,
declare its knowledge, and measure what the learner—not the outer loop—adds.

## Track split

### KRK engineering

May use the existing curriculum, exclusions, authored embodiment, oracle arms,
and aggressive tuning to solve KRK. Results in this track make no autonomy claim.

### Generic-core science

Moves outside `recon_lite_chess`. Freeze one learner and test:

1. delayed fork: persistent episode eligibility and terminal-only credit;
2. anonymous online XOR: online scalar-outcome structural discovery;
3. rare refutation: lower-tail/counterexample learning against a usually good
   action with one catastrophic response.

The same policy prediction must be updated by TD. Responsibility must derive
from actual activation traces. Growth must be triggered by learner-local
residuals and pay explicit resource/interference costs.

### Sealed confirmation and transfer

Only after the generic core passes frozen randomized tasks may a frozen release
return to fresh KRK pools. Independent roles must preregister, execute, analyze,
and adjudicate. A negative result completes a package; it does not authorize an
automatic rescue.
