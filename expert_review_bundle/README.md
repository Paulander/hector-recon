# ReCoN Expert Review Bundle

This folder is a compact context package for an external AI/expert review.

Attach all files in this folder together. The most important file to paste as the direct prompt is:

- `00_FINAL_PROMPT.md`

Supporting context:

- `01_system_overview.md`: ReCoN-lite architecture and intent.
- `02_current_status.md`: current KRK curriculum state and saved checkpoints.
- `03_curriculum_growth_and_artifacts.md`: training/growth mechanism and artifact map.
- `04_design_questions.md`: focused review questions.
- `05_glossary.md`: local terminology.

Small JSON artifacts copied from the latest runs:

- `stage5_fence_clean_run_manifest.json`
- `stage5_fence_clean_curriculum_history.json`
- `stage5_fence_conversion_debug.json`
- `stage2a_close_curriculum_history.json`
- `stage2b_enemy_between_curriculum_history.json`
- `stage2c_wrong_tempo_curriculum_history.json`

The expert should treat KRK as a controlled proving ground, not as the final target.
